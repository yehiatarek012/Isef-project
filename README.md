# AI Anemia Detection Project

## About the Project
This is a machine learning and web project I am building for the ISEF science competition. The main idea is to help people understand their blood test (CBC) results easily. 

Users can enter their blood test values manually, and the AI model analyzes these numbers to provide:
- **Anemia Detection:** Whether the person has anemia or not.
- **Severity Level:** How mild, moderate, or severe the anemia is.
- **Possible Causes:** What might be causing the anemia based on the test values.
- **Care Tips:** General health and nutrition advice to help improve their condition.

*(Note: This tool is for educational and awareness purposes only and does not replace a real doctor.)*

## Technologies Used
- **Python & Jupyter Notebook:** For data analysis and training the AI model.
- **HTML & CSS:** For building a simple and clean user interface.
